# Game design

_You (the human) own this folder. Agents read it but don't make design decisions._

Working idea: a network-building tycoon. Think Cisco Packet Tracer with an economy:
build and cable networks for customers, meet their requirements, earn money, grow.
Start as a flat 2D topology view; move to 3D rooms and racks later. Because all
rules live in the Sim, the view can change without rewriting the game.

Add one file per system as you design it, e.g. `devices.md`, `packets.md`,
`economy.md`, `customers.md`.
