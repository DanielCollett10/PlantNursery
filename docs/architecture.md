## Simulation core (planned for M1)

| Folder | Contents |
|---|---|
| `Sim/Core/` | `SimWorld` (tick clock, command queue, event list), `ICommand`, `CommandResult`, `PlayerId` |
| `Sim/Content/` | Content definitions and `ContentLoader` |
| `Sim/Time/` | `GameClock`: day, minute of day, phase, season; sleep |
| `Sim/Building/` | `Grid`, layers, footprints, placement, `BuildInventory` |
| `Sim/Economy/` | `Wallet`, supplier purchases |
| `Sim/Plants/` | `Plant`, containers (plug tray, pot), growth system |
| `Sim/Genetics/` | Genes, alleles, phenotype |
| `Sim/Hands/` | Per-player held item, watering can |

- `Sim/Content/`: `ContentLoader.Load(filesByName)` takes JSON strings (`time`, `items`, `containers`, `genes`, `varieties`, `economy`, `building`, optional `time.demo`) from `Assets/StreamingAssets/Content/`, validates them and returns an immutable `ContentDb`. Errors throw `ContentException` (file + field path).
- `Sim/Building/`: `BuildState` holds the floor grid (plot size from `building.json`), placed items and the shared `BuildInventory` (seeded from `economy.starterInventory`). `CanPlace`/`CanPickUp` are query-only and return a `BuildRejection`; `PlaceItem`/`PickUpItem` commands (registered via `BuildingModule.Register`) use the same checks and raise `ItemPlaced`/`ItemPickedUp`. The rejection name is the `CommandResult.Message`. `SurfaceGrid` (constructed with `ContentDb` + `BuildState`, which it registers as the `ISurfaceOccupancy`) is the 0.1 m mini-grid: `Unit(u,v)` = cell*5+offset across the plot; a unit is usable only over a placed floor item with `providesSurface`, so touching benches form one surface. `CanPlace/Place` take rotation-aware footprints and reject `Occupied` then `NoSurface`; `FindNearestFreeSpot(item, rotation, desired, radius)` returns the nearest valid anchor (squared Euclidean, ties smallest v then u) or null. `PickUpItem` on a bench with surface items returns `HasItemsOnTop`. Surface commands/inventory wiring are not yet added.
- `Sim/Hands/`: `HandsState(ContentDb, SurfaceGrid)` holds one `HeldItem` per `PlayerId` and the `ItemContents` (plants, water charges) of surface items, keyed by surface item id. `PickUp` removes the surface item from the grid into the hand (rejects `HandsFull`, `NotHoldable`); `PutDown` re-places it via `SurfaceGrid.CanPlace/Place` (rejects `NothingHeld`, `NoSurface`, `Occupied`) and moves its contents to the new id, so plants stay attached to trays and pots. Cans are items with `waterCapacity` (items.json) and start full; `RefillCan` fills to capacity (`NoCan`); `WaterPlant` sets moisture 100 and uses a charge (`NoCan`, `CanEmpty`, `PlantDead`). Commands `PickUp/PutDown/RefillCan/WaterPlant` are registered by `HandsModule.Register`; the rejection name is the result message. `Sim/Plants/Plant` holds the full plant model (id, variety, `Genome`, growth, stage, moisture, health, counters, `CellIndex`, isDead); growth rules are not yet implemented. `Sow(player, trayId, cellIndex)` (trays/pots are surface items whose item id matches a `ContainerDef`) needs a held `seed_packet` (`ItemContents.Seeds`, initialised from the surface item's `SeedCount`; `VarietyId` null = first content variety), then creates a Seed plant (moisture 50, health 100) with `Genome.FromVariety`, and raises `PlantSown`. Rejections: `NoSeedPacket`, `PacketEmpty`, `CellOccupied`, plus `UnknownContainer`, `InvalidCell`, `StageNotAccepted`. `Compost(player, plantId)` removes a dead plant (`NotDead` otherwise) and raises `PlantComposted`.
- `Sim/Plants/GrowthSystem` (`GrowthSystem.Install(world, content, hands, clock, config?)`) is an `ISimSystem` that updates every living plant each tick (found via `HandsState.CollectPlants`, which pairs each plant with its `ContainerDef`, whether the container is on a surface or in a hand): drying, water/season factors, growth capped at the container cap, `PlantStageChanged`, root-bound counter and health loss, wilting loss, recovery, death (`PlantDied`, then no more updates) and alive/goodCare counters. `GrowthSystem.CareScore` and `GradeOf` give the A/B/C grade. Health/grace/grade values live in `GrowthConfig` (defaults from plants.md; not yet loaded from JSON). Install it after `GameClock` so the season is current.
- `Sim/Economy/`: `Wallet` (shared coins, from `economy.startingMoney`, never below 0). `SupplierModule.Register(world, content, wallet, build, surface)` handles `BuyItem(player, itemId, qty)`: only items with price > 0; rejects `InsufficientFunds` (no change), `InvalidArgument` (unknown item / qty < 1) or `Blocked` with message `DeliveryShelfFull`. `seed_packet` is placed qty times on the placed `delivery_shelf` via `SurfaceGrid.FindNearestFreeSpot` (with an accept predicate keeping the packet on the shelf), as `SurfaceItem`s carrying `SeedCount` (`seedCount` in items.json); all-or-nothing. Everything else goes to `BuildInventory`. Raises `WalletChanged` and `ItemsPurchased`. `Validate` dry-runs shelf placement and rolls it back. `DeliveryShelf` (shared with the guard) finds the shelf and gives the nearest spot on it (`FindSpotOnShelf`) or on any surface (`FindSpotAnywhere`). `SoftLockGuard.Install(world, content, wallet, build, surface, hands, clock)` is an `ISimSystem` that, on each DayStarted tick, checks wallet < seed packet price, no living plant, and no seeds anywhere; if all hold it places one free packet (shelf, else any surface, else it waits a day), sets its variety, adds a plug tray only if none is owned anywhere, and raises `NeighbourGift`. Disabled by `softLockGuard.enabled`. Installed by `SimHost` (Unity layer).
- `Sim/Time/GameClock`: `GameClock.Install(world, timeConfig)` adds the clock system (raises `DayStartedEvent`, `SeasonChangedEvent`) and the `SleepCommand` handler. Tick 0 = Spring day 1 at `dayStartMinute`; days roll at `dayStartMinute`. Phase boundaries (`morningEndMinute`, `eveningStartMinute`, `nightStartMinute`) come from `time.json`; `IsNight`, `NeedRateMultiplier` (1 by day, `nightRateMultiplier` at night) and `RealSecondsPerTick` (`realSecondsDay` / playable minutes, constant) are the one place systems ask about night. Sleep (Evening/Night only, else `RejectReason.NotTired`) calls `SimWorld.RunUntil`, which makes `Step` keep stepping tick by tick until the next day start.
- `Sim/Genetics/`: `Genome` holds two alleles per content gene (copied; `Genome.FromVariety(db, varietyId)` copies a variety exactly). `Phenotype` has the pure rules: Mendelian = most dominant allele (earlier in the gene's `alleles` list), Blend = mean. `GenomeException` for unknown genes, alleles or varieties.
- `SimWorld` owns the tick clock. `Step(n)` advances time; nothing else does. 1 tick = 1 in-game minute.
- `SimWorld` is the SimContext (decision 0014). `new SimWorld(secondsPerTick, seed)` creates one seeded `SimRandom` (`world.Random`; systems must never use `System.Random`). `NextEntityId()` returns 1, 2, 3... and never reuses an id. Systems register with `AddSystem(system, SystemPhase)` and update each tick in phase order Time, Weather, Growth, Watering, Behaviour, Mobility, Orders, Economy (registration order only within a phase; `AddSystem(system)` means Behaviour). Weather is reserved (decision 0013) and has no systems by default. Same seed plus same commands gives identical state.
- Commands: `Submit(cmd)` queues; each `Step` tick first applies queued commands in submission order (validate, then apply, via the `ICommandHandler<T>` registered with `RegisterHandler`), then updates `ISimSystem`s. Rejections at apply time raise `CommandRejectedEvent`. `Validate(cmd)` is query-only. A paused world keeps commands queued.
- Events: handlers and systems call `Raise(ISimEvent)`; the Unity layer calls `DrainEvents()` each frame.

## Unity layer (planned for M1)
- Implemented: `Assets/Game/Host/SimHost.cs` (asmdef `PlantNursery.Game`). `Initialize()` loads `StreamingAssets/Content/*.json` (`UseDemoProfile` keeps/drops `time.demo.json`), builds SimWorld + GameClock + BuildState + SurfaceGrid + Wallet; `Advance(realSeconds)` steps ticks at `Clock.RealSecondsPerTick`; `Submit`/`Validate` pass commands; an accepted `SleepCommand` steps immediately to the next morning; `EventDispatched` relays drained events. `Plant Nursery/Generate Starter Scene` (`Assets/Editor/Scene`) writes `Assets/Scenes/Starter.unity`. EditMode tests: `Assets/Tests/EditMode`.
- UI (`Assets/Game/UI`, `Player/InteractionHud.cs`): every UIDocument (HUD, build panel) uses the one committed `Assets/Game/UI/GamePanelSettings.asset` (ScaleWithScreenSize 1920x1080, theme `UnityDefaultRuntimeTheme.tss`), created by `Assets/Editor/UI/GamePanelSettingsBuilder` and assigned by `StarterSceneGenerator`. Scripts never create PanelSettings. HUD sorts above the build panel (20 vs 10). HUD and shop are UI Toolkit, loaded from `Resources/UI/Hud.uxml` + `Hud.uss`; all text comes from `UiStrings` (`Resources/UI/strings.json`). `InteractionHud` shows day/season/clock/wallet/held/prompt, the NeighbourGift toast, and the computer shop (Buy sends `BuyItem`; rejections shown). Opening the shop disables `FirstPersonController` (frees the cursor); Esc/gamepad B/Close re-enables it. `SimHost` installs `SoftLockGuard`.
- `SimHost` MonoBehaviour owns the `SimWorld`, loads content, steps ticks at the real-time pace from `time.json`, and drains events.
- View scripts mirror sim state into prefabs (placeholder mesh as a child). The first-person controller sends commands.

## Data flow

Player input → Unity layer → Sim command → `SimWorld.Step` → Sim state + events → Unity layer renders.

## Build mode and put-down ghost (T-020)
`Assets/Game/Building/`: `BuildModeController` (own UIDocument, `Resources/UI/BuildPanel.uxml/.uss`) toggles with BuildToggle and lists floor items with `BuildInventory` count > 0 (choose with 1-9 or wheel). The floor ghost snaps to the aimed cell (ground-plane ray, centred footprint), R rotates, colour and rejection reason come from `SimHost.Validate(PlaceItem)`; Place submits `PlaceItem`, PickUpDrop on a placed item submits `PickUpItem`. While a Surface item is held (build mode or not) the same ghost snaps to the aimed mini-grid unit, is nudged by `SurfaceGrid.FindNearestFreeSpot(.., NudgeRadius)`, is coloured by `Validate(PutDown)`, and PickUpDrop submits `PutDown`. The only local rule is `BuildAim.CapsuleOverlaps` (floor placement blocked where the player stands). `BuildAim` is pure maths (unit-tested).

## World views (T-019)
`Assets/Game/Views/`: `WorldView` reconciles prefab instances against the full sim state every `LateUpdate` (floor items from `Build.PlacedItems`, surface items from `Surface.Items`, plants from `Hands.GetContents`), so loads rebuild and event-less changes (deliveries, gift) still appear; `RebuildAll()` forces it. `WorldLayout` is the pure cell/unit-to-metre, rotation-pivot, stage-scale and tint maths (unit-tested). `PlantView` builds the stem+leaves placeholder (leafColour tint, droop/desaturate when moisture < 20, brown-grey `#6E6253` when dead). Surface items sit on the top of the supporting floor view's renderer bounds. Held items (and plants inside held containers) are drawn by `HeldItemView`, not here.
